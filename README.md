# Project name : FitLog

# Description :
A dark, no-nonsense gym companion built with Next.js. Pick a lift, lock it into today's plan, and watch the week's work add up.

# Technologies used :
1. Next.js — Build the UI,
2. App Router (Next.js) — Handle page navigation
3. Tailwind CSS — Styling and responsiveness

# 5 key features of the project
1. Workout Library — Browse workouts from an API in a responsive grid layout.
2. Workout Details Page — View full details, specs table, and step-by-step instructions.
3. Today's Plan (Max 5 Lifts) — Add up to 5 workouts with a helpful toast when the limit is reached.
4. Saved Workouts — Save any workout for later and manage them in a separate tab.
5. Live Stats Dashboard — Real-time tracking of exercises, minutes, and calories.
6. Sort Workouts — Sort by Duration, Calories, or Rating.
7. Mark as Done & Remove — Mark workouts complete or remove them with instant toast feedback.
8. Data Persistence — Plan and saved workouts survive page reloads.
9. Responsive Design — Works perfectly on mobile, tablet, and desktop.
10. Custom 404 Page — A clean "Page Not Found" screen for invalid routes.
